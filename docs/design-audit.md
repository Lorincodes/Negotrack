# NegoTrack design audit

**Reference:** `public/reference/negotrack-feedhive-reference.png`  
**Final review date:** 4 August 2026  
**Independent finish disposition:** **SHIP**

## Direction retained

The final site keeps the reference's product-led SaaS composition: a daylight
surface, assertive midnight display type, mint/teal operating signals,
blue/violet analytical accents, hairline borders, soft product depth, a split
hero, a truthful launch strip, connected workflow, coded product surfaces,
alternating story panels, a capability matrix, and a bright closing CTA.

The supplied reference is stored as design evidence only. It is not rendered,
embedded, or used as a page background. Customer logos, testimonials, user
counts, ratings, and other invented proof were deliberately omitted.

## Material review and resolution

| Review finding | Final resolution |
| --- | --- |
| Product previews initially appeared incomplete before intersection | Scores and charts now render their authored values from first paint; motion begins from a legible baseline. |
| Hero console was too faint and miniature interface copy was weak | The opacity gate was removed and small labels, metrics, contrast, and chart strokes were strengthened. |
| Display hierarchy was lighter than the approved reference | Plus Jakarta Sans headings now use an assertive weight and the 1440px hero resolves to a compact three-line lockup. |
| Workflow connector began hidden | A complete connected route is visible before any viewport animation. |
| Mobile comparison clipped both meanings | The mobile layout presents complete traditional-audit and NegoTrack-explanation states while keeping the keyboard/touch range control. |
| Mobile selectors looked accidentally clipped | Monitoring, feature, and business-type controls use complete wrapping grids; the feature result cards use a visible-scrollbar snap rail. |
| Product-preview kickers read as decorative pills | Preview status moved into browser chrome or inline explanatory copy; the dated demonstration-data disclosure remains explicit. |
| Mobile captures repeated the opening viewport and omitted the footer | The capture process now stages scrolling and stitches viewport segments; both mobile full-page images contain one complete footer. |
| Overall page rhythm was too loose | Repeated section spacing and major panel heights were tightened; 1440px capture height fell from 11,254px to about 10,415px and 375px from 17,609px to 15,058px without removing requested content. |

The second independent re-review found all remaining items resolved and no
visible regressions. It specifically retained the hero hierarchy, honest demo
labels, waitlist prominence, mobile readability, and complete footer.

## Responsive audit

- **375px / 430px:** dedicated mobile dashboard composition, single-column
  product story, complete comparison states, wrapped selectors, snap feature
  rail, one-column waitlist form, and full footer.
- **768px:** mobile navigation with a recomposed tablet dashboard and balanced
  two-column intermediate layouts where space permits.
- **1024px:** compact dashboard navigation, reorganised health panels, and
  desktop-oriented story structure without horizontal overflow.
- **1440px:** reference-led split hero, complete product console, compact
  three-line headline, five-part launch strip, and four-column capabilities.

All score circles use square SVG view boxes and CSS aspect ratios. The browser
suite found no page-level horizontal overflow in either locale at any audited
width.

## Content and truth audit

- English and Spanish page structures are equivalent and use `en-GB` and
  `es-ES` routes and document languages.
- NegoTrack is consistently described as business-health and digital-growth
  software, never as a negotiation or sales-pipeline product.
- Product surfaces, scan results, company examples, and 2026 metrics are marked
  as preview or demonstration data.
- Planned capabilities display `Coming soon` labels.
- The launch statements are limited to UK/Spain context, language support,
  small-business intent, private-beta status, and no-obligation signup.
- The production logo asset remains unavailable; the UI uses a documented,
  deliberately plain text placeholder rather than a redrawn mark.
